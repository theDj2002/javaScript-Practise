# RideFlow Bike Rental Platform UI

Next.js 14 + TypeScript + Tailwind CSS + reusable component architecture for a modern bike rental experience.

## Run locally

```bash
npm install
npm run dev
```

## Structure

- `app/` App Router pages (public, user dashboard, admin dashboard)
- `components/` reusable layout/UI/feature components
- `services/api.ts` Axios API service placeholders
- `types/` domain types
- `hooks/` mock data and reusable hooks
